Bugs found & fixed during bring-up (all verified, not assumed):
1. Boot 4 package moves: WebServerApplicationContext -> web.server.context;
   TestRestTemplate -> spring-boot-resttestclient (+ spring-boot-restclient
   dep + @AutoConfigureTestRestTemplate).
2. Surefire skips *IT classes by default -> added includes so `mvn test`
   runs everything (initially only 23/28 tests ran).
3. GenerationType.IDENTITY emits broken DDL on Hibernate 7 SQLiteDialect
   (untyped `id` column -> not a rowid alias -> stored id NULL ->
   keyed lookups discarded). Proven via bind/extract tracing + JDBC
   cross-check; fixed with GenerationType.AUTO.
4. Thymeleaf `application` is a reserved implicit object — detail model
   attribute was shadowed; renamed to `app` (first tried T() enum compare,
   which did not fix it — wrong diagnosis, corrected on investigation).
